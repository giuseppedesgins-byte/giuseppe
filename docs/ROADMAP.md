# Roadmap

- **Phase 0, safety foundation:** secret rotated and removed from docs; branches and protected previews; staging database; safe build script; docs; rollback rehearsal. (Backups and Vercel plan upgrade decisions deferred; see costs in the audit.)
- **Phase 1, editorial essentials:** preview of unpublished stories, real cover image upload, feature-on-homepage picker, Founding 10 manager screen.
- **Phase 2, content studio:** homepage editor, media library (alt text, credit, licence, replace, resize).
- **Phase 3, polish:** Canva handoff guide, Issues screen, visual text toolbar, individual admin accounts with second factor, newsletter integration.
- **Before selling:** upgrade Vercel to Pro; backups on; end-to-end test orders on staging; Stripe live setup; attorney review of legal pages; rate limiting; make the admin cookie fail if its secret is missing.
